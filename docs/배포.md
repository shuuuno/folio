# Windows 팀 배포

## 팀원 설치

Windows 10/11 64비트에서 `Paperlight-0.9.1-Setup.exe`를 실행합니다. 기본 위치는 `%LOCALAPPDATA%\Programs\Paperlight`이며 관리자 권한이나 Python이 필요하지 않습니다. 설치 뒤 시작 메뉴에서 **Paperlight**를 실행합니다. 예제는 설치 폴더의 `시작하기.pdf`입니다. PDF를 앱 창으로 끌어 넣거나 파일 열기로 선택합니다.

포터블이 필요하면 `Paperlight-0.9.1-Portable.zip`을 풀고 폴더 안 `Paperlight.exe`를 실행합니다. `_internal` 등 나머지 파일도 함께 있어야 합니다. 설치판과 포터블은 같은 사용자 계정의 서명·복구 공간을 공유합니다.

아직 디지털 코드 서명을 하지 않은 빌드입니다. Windows 또는 회사 보안 정책이 실행을 제한할 수 있습니다. 배포받은 출처와 `SHA256SUMS.txt` 해시를 확인하고, 회사에서 차단한 경우 담당자에게 승인받으세요. 보안 프로그램을 끄는 절차는 필요하지 않습니다.

```powershell
Get-FileHash .\Paperlight-0.9.1-Setup.exe -Algorithm SHA256
```

## 업데이트와 제거

트레이 메뉴의 완전히 종료로 설치된 앱을 종료하고 새 설치 파일을 실행합니다. 기존 설치 위치에 덮어 설치하며 시작 메뉴 항목을 갱신합니다. 자동 업데이트는 하지 않습니다. PDF 기본 앱 후보로 등록하며 실제 기본 앱 선택은 Windows 설정에서 사용자가 합니다.

Windows **설정 → 앱 → 설치된 앱 → Paperlight → 제거** 또는 시작 메뉴의 **Paperlight 제거**로 삭제합니다. 제거 대상은 배포한 프로그램 파일입니다. 설치 폴더에 별도로 둔 사용자 문서는 남겨 두지만 문서는 일반 문서 폴더에 저장하는 것을 권장합니다. `%LOCALAPPDATA%\Paperlight\Paperlight`의 마지막 서명과 복구본은 유지됩니다. 이를 완전히 지우려면 모든 작업을 저장하고 앱을 닫은 다음 해당 데이터 폴더를 직접 정리합니다.

## 개발자 빌드

Python 3.13 x64, Git, Windows 맑은 고딕이 필요합니다. 팀원 PC에는 개발 도구가 필요 없습니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
# 변경 소스를 검토하고 커밋한 뒤 실행
.\.venv\Scripts\python.exe scripts\release.py
# 기존 설치가 없는 PC/계정의 격리된 경로에서 설치·제거 확인
.\.venv\Scripts\python.exe scripts\verify_installer.py
```

`release.py`는 `build/distribution/Paperlight`를 새로 만들고 `release/<버전>/`에 Setup EXE, Portable ZIP, Source ZIP, SHA256SUMS를 생성합니다. 기존 `dist/Paperlight`는 건드리지 않습니다. 소스 ZIP은 Git HEAD만 포함하며 빌드에는 커밋 ID를 기록합니다. NSIS 3.12는 공식 HTTPS 주소에서 받아 고정 해시와 비교합니다. `build/`, `dist/`, `release/`, `evidence/`, 내려받은 조사 자료·공개 PDF 원본은 Git에 넣지 않습니다. 같은 의존성으로 재빌드할 수 있지만 타임스탬프 때문에 바이트 단위 동일 빌드를 보장하지 않습니다.

GitHub Actions는 Windows에서 테스트·패키징 후 다운로드 가능한 아티팩트를 만듭니다. 공개 게시·팀원 초대·자동 릴리스 발행은 하지 않습니다. 저장소를 비공개로 유지하고 검증한 버전만 내부 공유합니다. Releases에 올릴 때 Setup, Portable, Source, SHA256 파일 네 개를 함께 첨부합니다. GitHub 접근 권한이 없는 팀원에게는 회사 내부 파일 공유로 설치 파일을 전달할 수 있습니다. 외부 배포 범위는 `THIRD_PARTY_NOTICES.md`를 참고하세요.

0.8.0부터 이미지/PDF/Office 변환을 지원합니다. DOC/DOCX·PPT/PPTX를 PDF로 바꾸는 PC에는 Microsoft Office 또는 LibreOffice가 필요합니다. 다른 방향은 앱만으로 처리합니다. Windows 기본 앱 후보 등록은 제거 시 정리하지만 사용자 선택(UserChoice)은 직접 변경하지 않습니다.
