# 검증 범위

합성 예제와 공개 문서만 사용했습니다. 개인 문서는 회귀시험·저장소에 포함하지 않습니다.

- 엔진: 한글 본문 교체·삭제, 주변 텍스트/이미지/도형 보존, 글꼴 대체, 실패 롤백, 암호화/서명 문서 읽기 전용, 원자 저장과 재개방.
- UI: 읽기 선택/복사, 검색, 페이지·도구 전환, 미적용 입력 보호, 텍스트·서명 추가/이동/크기 조절/삭제, 실행 취소, 저장 후 재편집.
- 복구: 5초 자동 저장 후 검증 전용 프로세스를 강제 종료하고 입력·객체를 복원, 재편집·저장·재개방. 실제 사용자 프로세스를 종료하지 않습니다.
- 공개 문서: 0.4~0.5에서 3종 148페이지의 저장/재개방·편집 보존을 검사했습니다. 출처/해시는 `research/corpus-sources.json`, 재현 스크립트는 `scripts/check_compatibility.py`입니다. 원본 PDF는 배포하지 않습니다.
- 배포: `scripts/verify_installer.py`는 기존 설치가 없는 경우 별도 경로에 설치하고 시작 메뉴·등록 정보·설치 파일 해시·실행·재설치·사용 중 설치/제거 차단·제거 후 사용자 파일 보존을 확인합니다. JSON 결과는 Git에서 제외한 `evidence/`에 기록합니다.
- 0.8: 탭별 미적용 입력·실행 취소 독립성, 같은 파일 중복 열기, 취소 시 모든 탭 복구본 보존, 별도 프로세스의 열기 전달, 이미지/편집 가능한 Office 결과, 실패한 묶음과 취소 시 결과 미게시를 검사합니다. 설치 QA는 기본 앱 후보 등록/제거와 기존 UserChoice 보존을 함께 확인합니다.
- 0.9: 활성 탭에 대한 상단 저장, 순서를 바꾼 탭의 닫기, 페이지 목록 접기, 1050×760 편집 패널·하단 탐색줄, 모드 전환 후 너비 맞춤을 검사합니다. 1400×960/1050×760의 읽기·편집·선택·서명·빈 화면을 캡처하고 별도 검토자의 지적 5건을 수정 후 재검토했습니다. Qt 검증은 사용자 데이터와 분리합니다.
- 0.9.1: 제목줄·탭 통합 후 활성 탭 순서 변경, 15개 탭에서 창 버튼 접근, 닫기 취소, 최대화 버튼·두 번 클릭을 검사합니다. Windows 실제 창에 네 모서리 hit-test를 보내 크기 조절 판정을 확인하고 최대화 시 작업 영역 보존, 최소화·복원도 확인합니다. 이동은 Qt의 OS 이동 API 호출을 시험했으며 실제 마우스 드래그 종단 시험과는 구분합니다.
- `.venv\Scripts\python.exe -m paperlight --verify-workspace evidence\workspace-check`는 실제 변환 자식 프로세스와 탭 화면을 확인합니다. `--verify-workspace-native`는 Windows 창과 가능한 경우 실제 트레이 숨김/복원을 확인하므로 실행 전에 사용자에게 새 검증 창을 알립니다. 사용자 데이터와 별도 설정을 사용합니다.
- Office가 설치된 PC에서 `scripts/verify_office_conversion.py`로 합성 DOCX/PPTX의 PDF 변환·한글 추출·원본 보존을 재현합니다. LibreOffice 경로는 코드에 포함하지만 이 PC에는 설치되지 않아 실제 실행을 확인하지 않았습니다.

Qt의 합성 입력 이벤트 시험은 실제 Windows 한국어 IME, 탐색기 드래그, 기본 파일 대화상자의 외부 마우스 조작 시험과 다릅니다. 후자는 도구 연결 문제로 확인하지 못했습니다. 다른 팀원 PC와 회사 보안 정책에서의 설치는 실제 사용자 확인이 남습니다. OCR, 인증서 전자서명, 문서 전체 재배치는 지원하지 않습니다.

## 0.9.2 글자 렌더링과 Folio 표시

동일한 Pretendard Variable의 Windows DirectWrite/FreeType 출력을 비교해 메뉴 한글 획의 거친 렌더링을 재현했습니다. 앱 생성 시에만 Windows FreeType을 선택하고 세로 힌팅·안티앨리어싱을 적용합니다. 시스템 설정과 PDF 본문 렌더링은 변경하지 않습니다. Folio 워드마크는 실제 Qt 텍스트이며 창 제목·트레이도 표시 이름을 따릅니다. 데이터·IPC·설치 식별자는 Paperlight로 유지합니다.

UI 테스트 30개와 작업 공간 테스트 10개가 통과했습니다. 네이티브 검증은 최소 1050×760과 기본 창에서 텍스트 편집·빈 상태 화면을 캡처하고, 탭 독립 상태·변환 자식 프로세스·두 번째 실행 전달·트레이 숨김/복원·창 크기 조절 판정과 최소화/최대화/복원을 통과했습니다. 증거는 `evidence/v092-native/workspace-check.json`과 같은 폴더의 화면입니다. 동일 환경 비교 결과이며 모든 Windows 디스플레이 설정의 시각 품질을 보장하는 검사는 아닙니다.

## 0.10 UI 정리와 Folio 이름 통일

단위 테스트는 빈 문서·페이지 경계 탐색, 변환 형식별 옵션, 서명 유무에 따른 적용 상태를 포함한다. 네이티브 작업 공간 검증은 960×640에서 속성 패널 가로 넘침이 없는지와 적용 버튼 접근, 창·탭·변환·트레이를 검사한다. 변환·서명·복구·확인 대화상자와 빈 화면을 이전 버전과 비교한다. kill-ai-slop의 웹 스캐너는 Python을 읽지 않으므로 QSS 추출 검사와 실제 화면·코드 수동 점검을 병행한다. 단순 선 아이콘, 상태 색상, 문서 그림자는 각각 기능·상태·페이지 구분을 위한 요소로 유지한다.

설치 검증의 `--upgrade-from` 옵션은 이전 Paperlight 설치판을 격리 폴더에 설치한 뒤 Folio로 업데이트한다. 구버전 실행 중 업데이트 차단, 이전 실행 파일·시작 메뉴 교체, 사용자 파일 보존, 같은 Paperlight.PDF ProgID의 Folio 열기 명령, UserChoice/Hash 유지, 구버전 생성 복구본의 미적용 입력·텍스트·서명·편집 객체 복원 및 새 저장을 확인한다. QApplication 종료 전에 검증 창을 명시적으로 정리해 검증 프로그램의 창·타이머 해제 순서를 고정한다. 이는 이전에 관찰된 일회성 종료 오류의 원인을 확정했다는 뜻은 아니다.
